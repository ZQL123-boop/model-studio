# 任务：给对话加「停止生成」

在 `web/src/components/ChatPanel.tsx` 里实现：生成中时「发送」按钮变成「停止」，
点击后中断 SSE 流。

## 需求

1. **立即中断**正在进行的 SSE 流（不能等它自然结束）
2. **保留**已经生成的内容（不能清空）
3. 按钮恢复成「发送」，输入框可以马上用
4. **不弹错误提示**（用户主动取消不算错误）

## 边界要求

1. 连续点两次「停止」不能报错
2. 中断后立刻重新发送，新请求不受影响
3. 中断时正在累积的 `tool_calls` 不能污染下一次请求
4. 从对话 tab 切到其他 tab 时，如果正在生成，应当中断

## 验收标准

- [ ] 生成中点「停止」，文字 **1 秒内**停止增长
- [ ] 停止后已生成的内容还在
- [ ] 按钮变回「发送」，能立刻发下一条
- [ ] 连点两次「停止」不报错、不卡死
- [ ] 停止后立刻再发，回答完整正常
- [ ] 停止时**没有**红色错误提示
- [ ] 浏览器 Network 面板里该请求状态是 `canceled`（不是 `200`）

> 最后一条最关键：状态是 `200` 说明只改了 UI，请求其实跑完了。

## 约束

- `web/src/api.ts` 里 `streamSSE` 的**现有参数不能变**（可以加可选参数）
- 不要把流式改成非流式
- 不要动后端 `app/main.py`

## 代码风格

- 跟现有代码保持一致：函数组件 + hooks，不引入新依赖
- 注释写「为什么」，不写「是什么」
- 改动尽量小，不要顺手重构无关代码
